# Aetheria (play build)

This repository holds only the built web version of Aetheria, a pixel-art
fantasy action RPG. It contains no source code.

Play: https://krabbyjoey-tech.github.io/aetheria-play/

## Install on iPad / iPhone
1. Open the link in Safari.
2. Wait for the game to load the first time (about 45 MB).
3. Tap Share, then Add to Home Screen.
4. Open Aetheria from the Home Screen: it runs full screen, and after the
   first load it also works offline.

Saves stay on the device, in the app's own storage.
